# Pets — сайт поиска домашних животных

Одностраничное веб-приложение на React: объявления о пропавших и найденных животных, карточки, поиск, личный кабинет.

**Стек:** React 18, React Router 7, Bootstrap 5 / React-Bootstrap

## Возможности

- список карточек животных и страница с подробностями;
- форма поиска животных и раздел найденных питомцев;
- регистрация и личный кабинет;
- добавление объявлений;
- адаптивная вёрстка.

## Данные

Списки животных и пользователи приходят с внешнего учебного API (`pets.сделай.site`). Без доступа к нему страницы открываются, но списки остаются пустыми («Идёт загрузка»).

## Запуск

```bash
npm install
npm start        # http://localhost:3000
npm run build    # production-сборка
```
